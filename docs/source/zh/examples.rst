示例
====

本项目提供多个示例脚本，展示如何读取输入与控制效果：

- ``examples/leds.py``：设置触控板灯颜色、玩家编号灯、麦克风静音
- ``examples/effects.py``：设置左右震动与扳机效果（Rigid、Pulse 等）
- ``examples/read_controller.py``：订阅事件（按钮、摇杆、陀螺仪）
- ``examples/read_all_input_channels.py``：使用 curses 显示所有输入通道
- ``examples/test_trigger_value.py``：打印 L2/R2 扳机的模拟值

提示：执行示例前，请确保设备已连接并安装了平台所需的 HIDAPI 依赖。
