# Examples

<details open>
<summary>English</summary>

This folder contains some examples on applications for the library and its usage.

## leds.py

The leds.py shows you how you can interact and change the lights of the controller.

## effects.py

The effects.py shows some effects of the controller.

## read_controller.py

The read_controller.py displays how you can access the button state of the controller.

## test_trigger_value.py

The `test_trigger_value.py` shows the left / right trigger analog value changing when pressing the button (range from 0 to 255).

## read_all_input_channels.py

Displays all controller input channels in a terminal UI (curses).

## hid_packet_logger.py

Logs HID input/output packets to the `examples/logs` directory.

## logs/clean_log_cache.py

Deletes all `.log` files in the current `examples/logs` directory.

## test_bt_connection.py

Interactive Bluetooth connection test; prints real-time input and supports runtime commands.

</details>

<details>
<summary>中文</summary>

此目录包含一些示例脚本，演示如何使用该库。

## leds.py

演示如何设置触控板灯颜色、玩家编号灯等。

## effects.py

演示震动与扳机效果（如 Rigid、Pulse 等）。

## read_controller.py

演示如何读取与订阅按钮状态。

## test_trigger_value.py

打印左右扳机的模拟值变化（范围 0–255）。

## read_all_input_channels.py

以终端界面显示所有输入通道（curses）。

## hid_packet_logger.py

记录 HID 输入/输出报文到 `examples/logs` 目录。

## logs/clean_log_cache.py

清理当前 `examples/logs` 目录下的所有 `.log` 文件。

## test_bt_connection.py

蓝牙连接交互式测试，实时打印输入并支持命令交互。
